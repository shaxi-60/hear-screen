听见画面 1.0
把屏幕上的视频和画面，变成视障用户可以听懂的实时解说。

════════ 一、第一次使用 ════════

1. 双击桌面上的「听见画面」快捷方式。
2. 点「设置」→「AI 服务」。
3. 填入火山方舟的 API Key：
   · API 地址：https://ark.cn-beijing.volces.com/api/v3
   · 模型 ID：doubao-seed-1-6-vision-250815
     （如果控制台显示 ep- 开头的推理接入点 ID，也可以直接填）
   · API Key：粘贴你创建的 Key
4. 点「测试连接」，听到“连接成功”后，点「保存并关闭」。
5. 打开抖音、B 站等视频，按 Ctrl+Alt+S 开始实时解说。

没有 API Key 时，程序不能工作。Key 需要在火山方舟控制台
https://console.volcengine.com/ark 开通视觉模型后创建。

════════ 二、快捷键 ════════

Ctrl+Alt+S   开始 / 停止实时解说
Ctrl+Alt+D   描述当前画面（可反复按）
Ctrl+Alt+P   暂停 / 继续实时观察
Ctrl+Alt+X   立即停止朗读
Ctrl+Alt+M   显示 / 收起迷你悬浮条
             （被占用时自动改用 Ctrl+Alt+B）
F1           打开使用说明
Ctrl+,       打开设置

所有功能也都有大按钮，不一定要记快捷键。

════════ 三、解说范围 ════════

· 跟随当前窗口（推荐）：自动跟住最前面的视频窗口。
· 全屏（鼠标所在屏幕）：把鼠标移到目标显示器再开始。
· 自定义区域：点“框选区域”，只框住播放器。

建议用自定义区域只框播放器：更省费用，也避免把聊天、密码等
敏感内容发给 AI。

════════ 四、设置建议 ════════

· 观察间隔：默认 4.5 秒；实时追剧建议 4～5 秒。
· 视频原声已经能听到时，不要勾选“同时朗读字幕/台词”，
  AI 会专注补充画面、动作、表情。
· 视频静音时才勾选“同时朗读字幕/台词”。
· 新解说会打断上一句，保证跟得上最新画面，这是正常的。
· 语速、音量在“设置 → 语音”里调整，可先点“试听这段声音”。

════════ 五、隐私 ════════

· 截图只在内存中处理，不会保存到硬盘；当前一帧会发送到你
  填写的 AI 接口。
· API Key 用 Windows 当前用户的 DPAPI 加密，保存在本机。
· 不收集遥测，不访问你配置之外的服务器。
· 配置和日志在程序目录的 data 文件夹：
  %LOCALAPPDATA%\Programs\听见画面\data

════════ 六、常见问题 ════════

401/403：Key 无效、过期，或模型未开通。
404：模型 ID 或接口地址不对，去控制台复制准确的 ID。
429：请求太频繁或余额不足，把间隔调大或充值。
黑屏：部分版权视频禁止截屏，或播放器用了独占全屏；
      改用窗口播放，或选“全屏/自定义区域”。
没有声音：在 Windows 设置 → 时间和语言 → 语音 安装中文语音包；
      检查音量、默认输出设备，在设置里点“试听”。
快捷键无效：可能被其他软件占用，界面按钮仍可用。
提示已经在运行：只允许开一个实例，按 Ctrl+Alt+M 找悬浮条。

════════ 七、局限 ════════

· 受网络和模型速度影响，通常有 3～8 秒延迟，不是逐帧直播。
· AI 可能看错或编造；重要信息请谨慎对待。
· 需要联网和 API 额度，每次请求按 token 计费。
· 不能用于避障、导航等安全关键场景。
